# Mama Beauty Studio

A responsive, single-page website for Mama Beauty Studio, featuring service and bridal sections, WhatsApp contact links, animated atmosphere transitions, and optional Three.js ambient effects.

## Project files

- `index.html` — page content and metadata
- `styles.css` — layout, responsive styling, and animations
- `script.js` — navigation, atmosphere transitions, and interactive effects

## Run locally

Open `index.html` in a modern browser. For a local web server, run this command from the project folder:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## External resources

The site loads Google Fonts, Three.js from cdnjs, and salon imagery from Unsplash. An internet connection is needed for these resources. The Three.js visual effect is skipped if the library cannot be loaded.

## Customization

Update the page content in `index.html`, visual styles in `styles.css`, and interactive behavior in `script.js`. Replace the remote image URLs with properly licensed studio photography when available.
